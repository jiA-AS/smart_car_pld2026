# FPGA ↔ ESP32 通信协议定义（V1.0 上行 / V1.1 下行）

## 物理层

| 项 | 值 |
|---|---|
| 接口 | UART，115200 bps，8N1，LVCMOS33（3.3V） |
| 上行 | ESP32 GPIO42(TX) → J1-3 UART2_RXD → FPGA **E13** |
| 下行 | FPGA **F14** → J1-1 GBC_LED → ESP32 GPIO41(RX) |
| 共地 | J1-5 GND ↔ ESP32 GND（必须） |

## CRC 算法（两个方向共用）

CRC-8/SMBUS：多项式 0x07，初值 0x00，非反射，异或出 0x00。
FPGA 侧：`v1_decode.v` / `ctrl_link_tx.v` 内 `crc8_next`；
ESP32 侧：`lib/fpga_link/protocol_v1.h` 内 `crc8_smbus()`。

## 上行 V1.0：ESP32 → FPGA（100Hz，34 字节）

| 字节 | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0-1 | `AA 55` | — | 帧头 |
| 2 | 版本 | u8 | 固定 0x01 |
| 3-4 | timestamp | u16 小端 | 发送时刻 millis() 低 16 位 |
| 5-8 | enc0 | i32 小端 | MOTOR1 编码器累计脉冲 |
| 9-12 | enc1 | i32 小端 | MOTOR2 |
| 13-16 | enc2 | i32 小端 | MOTOR3 |
| 17-20 | enc3 | i32 小端 | MOTOR4 |
| 21-22 | gyro_x | i16 小端 | IMU 原始值（LSM6DS3，±250dps 档，8.75mdps/LSB） |
| 23-24 | gyro_y | i16 小端 | 同上 |
| 25-26 | gyro_z | i16 小端 | 同上（航向角积分用这个轴） |
| 27-28 | acc_x | i16 小端 | 加速度原始值（±2g 档） |
| 29-30 | acc_y | i16 小端 | 同上 |
| 31-32 | acc_z | i16 小端 | 同上 |
| 33 | CRC8 | u8 | 覆盖字节 2~32（共 31 字节，不含帧头） |

- FPGA 端解析：`v1_decode.v`，好帧产生 `parse_done` 单拍脉冲，`parse_result=0x00`；CRC 错 `parse_result=0xE3`；
- 测试帧（结尾 0x29 为好帧，0x28 为坏帧）：
  `AA 55 01 E8 03 64 00 00 00 9C FF FF FF E8 03 00 00 00 00 00 00 01 00 02 00 03 00 64 00 C8 00 00 40 29`

## 下行 V1.1：FPGA → ESP32（50Hz，9 字节）

| 字节 | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0-1 | `55 AA` | — | 帧头（与上行 AA 55 方向相反，防止自环混淆） |
| 2 | 版本 | u8 | 固定 0x02 |
| 3 | mode | u8 | 0=停车 1=速度控制 2=搜索（原地转） |
| 4-5 | left_speed | i16 小端 | 左轮目标速度 -100~+100（%） |
| 6-7 | right_speed | i16 小端 | 右轮目标速度 -100~+100（%） |
| 8 | CRC8 | u8 | 覆盖前 8 字节 |

- ESP32 端**看门狗：200ms 收不到合法帧 → 立即停车**；
- mode=0 时速度字段忽略，直接停车；
- 模式仲裁：遥控器 s1 下=遥控驾驶 / 中=停车 / 上=视觉模式（执行 V1.1 指令），任何模式 dbus 失联 → 停车。

## 当前 FPGA 发送内容（冒烟测试专用）

`mode=0`（停车，安全）；`left` 借道传 enc0 低 16 位、`right` 传 timestamp——
ESP32 解析器串口打印时应能看到 left 字段随转轮变化，用于验证下行通路。
阶段 3 接 tracker_ctrl 后改发真实速度指令。
