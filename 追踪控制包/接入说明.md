# 追踪控制接入说明

功能：FPGA 根据绿灯识别结果实时算出左右轮速度，经 V1.1 下行帧（50Hz）发给 ESP32 直接驱动电机。
实现"正对绿光 + 保持一定距离 + 丢灯自动搜索"。

## 一、文件替换/新增

| 文件 | 操作 |
|---|---|
| tracker_ctrl.v | **新增**，Add Sources 加入工程（不勾 Copy） |
| sensor_link.v | **替换**工程里同名文件（UART移植包那版） |

## 二、顶层改 4 根线（u_sensor_link 例化）

在 top_dual_ov5640_lcd.v 的 u_sensor_link 例化里，`.uart_txd(uart_txd),` 之后加：

```verilog
    .gd_found     (gd_found),
    .gd_u         (gd_u),
    .gd_min_y     (gd_min_y),
    .gd_max_y     (gd_max_y),
```

另外末尾三个监视口可以悬空（也可接 ILA 调试用）：

```verilog
    .trk_mode     (),
    .trk_left     (),
    .trk_right    (),
```

gd_v/gd_min_x/gd_max_x/gd_cnt 不接入（识别框照常用，不冲突）。改完直接 Generate Bitstream。

## 三、控制逻辑速览（答辩可直接讲）

- **比例导引**：err = 灯心横坐标 − 画面中线 200；转向量 = err/4；左轮 = 基准 + 转向，右轮 = 基准 − 转向。偏差大转得快，偏差小转得慢，居中后直行——这就是比例（P）控制
- **距离保持**：包围盒高度 h 是距离的代理量（灯越近越大）。基准速度 = (H_REF − h)/2：远了加速、近了减速、到达 H_ARRIVE 停车
- **四状态机**：追踪 → 丢灯保持 0.5s（惯性强，过遮挡不慌）→ 原地慢转搜索（转向灯最后消失的一侧）→ 找回继续；到达后灯移远会自动重新跟上

## 四、首次上车调试（务必架轮测试！）

1. **架空车轮**上电：FPGA 上电默认处于搜索态，四个轮子应低速旋转（两侧反向）；绿灯伸到右摄前 → 轮速随灯的方位变化；灯移近到很近 → 停转
2. **标定 H_REF / H_ARRIVE**（sensor_link.v 例化 tracker_ctrl 的参数）：
   - 把车放在你想停的距离上，用 ILA 或识别框目测此时包围盒高度 h
   - H_REF 设为该值，H_ARRIVE 设为该值的 1.2 倍左右
3. **V_MAX=45 起步**，响应太猛降 V_MAX 或把 tracker_ctrl 里 `>>> 2` 改 `>>> 3`（Kp 减半）
4. 确认方向无误后落地，先空旷场地低速试

## 五、ESP32 端要确认的事

- V1.1 解析时 left/right 必须按**有符号 int16** 解释（负数=反转），符号位在字节高位
- 遥控器仲裁保持：s1 上档才进入视觉模式（FPGA 指令生效），中档停车——这是你的安全绳，调试期随时拨回
- 200ms 看门狗已有，FPGA 端异常停发时 ESP32 自动停车

## 六、关于"所有传感器综合在 FPGA 端"

当前架构：视觉（FPGA）直接出速度 → ESP32 只做 PWM 执行。编码器/IMU 已上行到 FPGA 且解包就绪，后续两个增强（都有现成模块，需要时说）：

1. **编码器速度闭环**：用 enc0~3 帧间差分算实际轮速，与指令比较做 PI 修正，克服两侧电机差异导致的跑偏——直线更直
2. **丢灯陀螺仪兜底**：S_LOST 期间用 gyro_z 积分保持原航向（attitude.v 已有），搜索转向角也可量化——这是"多传感器融合"在控制层的体现，答辩加分

## 七、常见现象对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 轮子一直转圈不停 | 找不到灯/阈值丢了 | 先确认识别框还在；SEARCH_SPD 降到 15 |
| 对着灯左右摇摆 | Kp 偏大或死区太小 | turn 的 >>>2 改 >>>3；DEADZONE 升到 12 |
| 到距离不停 | H_ARRIVE 标定偏小 | 实测此时 h，重设 H_ARRIVE |
| 越追越远 | 速度符号/左右轮映射反 | 先确认 ESP32 端 left 对应左轮组（MOTOR1+2） |
| 直行时跑偏 | 两电机差异 | 短期：给较快一侧软件限幅；根治：编码器闭环（六.1） |
